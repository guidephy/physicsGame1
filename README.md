# 物理擂台｜GitHub Pages 版

六位角色：牛頓、法拉第、克卜勒、楊氏、波耳、愛因斯坦。

**純 HTML、JavaScript、CSS，無 React、無 npm、無後端。** 附原創 PNG 精靈圖。可以放在 GitHub Pages 的個人網站或儲存庫子路徑，沒有固定網域，也沒有外部套件或字型載入需求。

## 上傳步驟

1. 解壓縮 ZIP。
2. 將裡面的 `index.html`、`styles.css`、`boot.js`、`main.js`、`game` 資料夾、`assets` 資料夾、`favicon.svg` 和 `.nojekyll` 放到你的 GitHub 儲存庫根目錄。**不要只上傳 ZIP 本身，也不要多包一層資料夾。**
3. 在 GitHub 儲存庫的 Settings → Pages 中，Source 選 Deploy from a branch，選擇上傳的分支（通常 main）與 `/ (root)`，儲存。
4. 等 GitHub Pages 完成發布後，開啟 Pages 顯示的網站網址。

可參考 [GitHub 官方發布來源設定說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

`tests`、`README.md`、`新增角色說明.md` 不影響遊戲，可一起上傳或自行保留。

玩家 2 預設使用上排數字鍵；數字鍵盤可在操作設定自行指定。按鍵全程顯示於對戰畫面下方，改鍵後同步更新。按鍵設定與音效偏好只存在自己的瀏覽器。

手機／平板直接按畫面下方的方向與攻擊按鈕，支援多指同時操作。橫向遊玩空間較大；同機雙人建議電腦鍵盤或大型平板。

## 規則

- 一對一、三戰兩勝，每回合 60 秒。時間到比較剩餘血量；平手重開一回合。
- 隨機題目的勝方返回戰場後自動施放本次大小絕招，無須按鍵或等待能量。
- 能量隨時間與攻防累積。基本出招需再次按下，不會因長按而連發。
- 可移動、跳躍、防禦。強招有預告或起手時間。
- 切換視窗會自動暫停；需按繼續或 Esc 才恢复。
- 電腦有入門、標準、挑戰三個難度。

## 本機預覽

先完整解壓縮，再雙擊 `index.html` 即可。此修正版使用依序載入的一般 JavaScript 腳本，不再依賴模組載入，所以不需要本機伺服器。上傳 GitHub Pages 也使用完全相同的檔案。請勿從 ZIP 預覽視窗直接開啟 HTML。

若要測試網站形式，也可以用現有的靜態網站預覽工具。若缺少腳本或啟動發生錯誤，頁面會顯示原因與重試按鈕，不會只停留在準備畫面。

## 修改與測試

### 搶答自動施招更新（目前規則）

已移除大小絕招按鈕、快捷鍵及改鍵項目。隨機搶答的勝方會在解說結束、返回戰場的第一個遊戲步驟自動施放本次招式，不需額外按鍵，不保留待用資格。真人與 CPU 相同；沒有人答對就不施招。勝方原有翻滾或硬直會在自動施招時結束，避免已答對卻無法出招。搶答、答錯內傷與自動恢復對戰規則保留。

下方舊版的「取得一次資格後手動施放」說明不再適用。

### 2026-09-11 隨機搶答版（目前規則）

本節取代下方舊版「按絕招鍵觸發個人答題」與「答錯不扣血」規則。

- 每回合開始對戰後約 5–8 秒隨機出題，之後相隔約 12–20 秒戰鬥時間。從 18 題中隨機選題，同時隨機決定本次獎勵是小絕招或大絕招。按絕招鍵不會再呼叫題目。
- 雙人看到同一題、同一组选項，每人限答一次；**先答對**者取得自己角色的該類絕招一次資格，並補足施招所需能量。其他人無法領取本次獎勵；以前取得且尚未使用的資格保留，不累積超過一次。
- 題目顯示 10 秒，作答期間雙方戰鬥與計時器暫停。開題前 0.8 秒是準備時間，防止戰鬥按鍵誤作答。1P 預設 J／K／L 選 A／B／C；2P 用上排 1／2／3。改鍵後會跟隨各自拳、踢、防禦鍵，畫面也顯示對應鍵。手機使用各玩家區的 A／B／C 按鈕。
- 不作答無扣血、無其他處罰。答錯扣 **5 HP**、最低保留 1 HP，該玩家本題不能重答；答題卡有內傷動作，回戰場也有紅色裂紋與扣血字樣。若另一人仍可回答，不會提前公開正確答案。
- 有人答對、雙方都答錯或逾時時結算，顯示答案解說，5 秒後自動回戰場，也可按「立即回戰場」。切換視窗時搶答時間與 CPU 思考一同暫停。
- CPU 先顯示讀題／推理，約 2.5–5.5 秒後作答；每次預定作答有 70% 機率選對，答錯同樣扣血。若玩家先答對，CPU 不會再作答。70% 是長期機率，不保證每 10 題恰好答對 7 題；練習模式不設競爭對手。
- 施放大小絕招時新增醒目字幕，顯示玩家、SPECIAL／ULTIMATE 與中文招式名稱。低動態設定會減少字幕滑動與內傷震動。

自動測試 30 項通過，含搶答順序、限答一次、未答無損失、CPU 延遲及 10,000 次機率抽樣、資格與能量發放、內傷與字幕資料；仍需實機試玩調整題目閱讀時間與搶答節奏。

### 2026-09-10 物理學習與閃避版

- 玩家的小絕招與大絕招都要先答對一道角色相關題目，獲得該招式的一次資格；答題不會直接攻擊，按「理解了，立即回戰場」即恢復對戰，再按絕招鍵選擇施放時機；不需額外按繼續。仍需滿足原有能量、冷卻與動作硬直條件。
- 作答時雙方與計時器一起暫停，沒有答題時限。答錯或先離開不扣血、不扣能量，顯示解說，戰鬥繼續 5 秒後可重新挑戰。每個回合重新取得資格。
- 六角色共 18 題，涵蓋物理史、概念與簡單推理。題庫在 `game/learning.js`，可擴充；本題庫是入門練習，不是學習成效測驗。雙人模式兩位真人都適用相同題目門檻；CPU 不作答，答題暫停期間也不行動。
- 翻滾：玩家 1 **O**、玩家 2 **上排 6**，手機新增「翻滾」按鈕。預設向後，按住左右可指定方向；持續約 0.42 秒、前約 0.30 秒可閃傷害，尾段有破綻，冷卻 1.5 秒。只能在地面且無其他硬直時發動，不能長按連續翻滾。
- 強化施法光暈、公式、絕招擴散光線、蘋果與電弧演出，新增翻滾旋轉。低動態設定保留；判定範圍沒有因美術放大而擴大。
- 26 項自動測試通過，涵蓋答題門檻、一次資格、答錯、雙人／CPU 規則及翻滾無敵與破綻。已透過瀏覽器驗證答對解說、返回／恢復、解鎖施放。實機觸控、長時間效能及教學節奏仍需真人試玩。

### 2026-09-08 商品化優化試玩版

- 新增「練習教室」：七種動作進度提示、無限時間、能量自動補滿、靜止練習靶；受擊後約 3 秒自動回血，不會 KO。小絕招仍有冷卻，所有招式仍有硬直。
- 改善格鬥手感：120 毫秒預輸入、短按保留、拳腳有效判定窗、同時互打公平判定與牆角分離。基本出招仍不會長按連發。
- 手機單人模式隱藏對手操作卡，提供較大的方向與攻擊按鈕；方向區可滑動換方向，直向補充角色提示。電腦保留雙人按鍵完整顯示。
- 小絕招顯示能量不足／冷卻／可施放，大絕招顯示能量進度與就緒狀態。實際按下的操作鍵有視覺回饋。
- 「操作與招式 → 遊玩體驗」提供可保存的低動態效果與音效開關。戰場增加側光、落地投影、拳踢軌跡及火花拖尾；音效區分攻擊、格擋、施法、KO 與回合。

本輪 21 項自動測試通過，包含六角色 36 組配對、輸入、互打、回合與練習規則。瀏覽器檢查涵蓋 390×844、844×390、1366×768、1280×600，並檢查練習進度、暫停／恢復、操作設定。尺寸模擬不等同手機實機多點觸控與效能驗收。

本版本是商品化方向的可玩試玩版，並非已完成發行驗收的正式商品。人物仍使用四個主要姿勢；逐格動畫、素材權利清冊、長時間實機效能、真人平衡及平台發行條件見《商品化檢核.md》。純靜態網站可直接上傳，不需安裝套件或建置。

電腦畫面會依視窗可用高度等比例縮放戰場，保留血量、工具列與雙人操作按鍵。已在 1366×768、1280×600 與 646×698 的瀏覽器視窗確認對戰畫面無須上下捲動；較小手機畫面仍採原有響應式配置。

人物資料位於 `game/roster.js`，招式處理位於 `game/engine.js`，繪圖位於 `game/render.js`。詳細擴充方法見《新增角色說明.md》。

若有 Node.js，可執行 `node --test tests/combat.test.js`；執行遊戲本身不需要 Node.js。

已做純引擎自動測試與程式語法檢查；修正版也在瀏覽器透過 HTTP 實際確認選角、開始對戰、電腦攻擊、倒數與暫停，未出現啟動錯誤。直接開啟檔案的模式已改用一般腳本支援，但目前測試工具不允許開啟 file:// 網址，未完成此模式的瀏覽器實測。手機實機觸控、多人鍵盤漏鍵與對戰平衡仍需試玩確認。WebMCP 為可選功能，未在支援此功能的瀏覽器中做工具呼叫驗證。

## 科學與美術

招式圖形更新：牛頓使用紅蘋果與環繞蘋果引力場；法拉第使用銅線圈與電弧；克卜勒使用帶環行星；楊氏使用雙狹縫波前與干涉光帶；波耳使用原子能階符號與四色光譜；愛因斯坦使用光子波包與彎曲時空網格。圖形以 Canvas 即時繪製，無額外圖片下載，保留原有招式判定與減少動態效果設定。可開啟 `招式圖鑑.html` 查看十二種招式定格預覽，或從遊戲說明中的連結進入。

知識依使用者提供的兩份物理史教材整理；原教材不包含在此網站內。波耳年代校正依 [諾貝爾獎人物資料](https://www.nobelprize.org/laureate/27)。招式是科學概念的創意演出，不是精確的物理模擬。

角色圖為本專案生成的原創素材，未使用 KOF 或 Science Kombat 的人物圖片、程式或音效。第一版使用四個主要姿勢，搭配位移、縮放、旋轉與物理特效；若希望接近商業格鬥遊戲，可後續增加走路、跳躍、受擊等逐格動畫。
